# Node 26 (2026-10-30)

Decided by the user, from Dependabot #2 (`node:22.23.3-alpine` → `node:26.12.1-alpine`).

**Context.** Node 26 became the Active LTS line in October 2026; 22 is in maintenance. Dependabot bumped only
the Docker images, which would have shipped 26 while CI, the tests and host development ran 22.

**Decision.** One Node major everywhere:

| Where                         | Now                                                       |
| ----------------------------- | --------------------------------------------------------- |
| Docker image (build and run)  | `node:26.12.1-alpine`                                     |
| CI, host development (`nvm`)  | `.nvmrc` = `26`                                           |
| `package.json` `engines.node` | `>=26`                                                    |
| `@types/node`                 | `^26`                                                     |
| Portless                      | `0.15.12`, pinned exactly (0.14+ needs Node 24, now fine) |

**Consequences.**

- Node 25 and later do not bundle corepack. The Dockerfile installs `corepack@0.36.0` and enables it, so pnpm
  still comes from `packageManager` (one pin). CI uses `pnpm/action-setup`, which never needed corepack. On a
  host: `npm install --global corepack && corepack enable` once.
- Supersedes the Node 22 line in `CLAUDE.md` and the "pinned to 0.13.0 because of Node 22" note in the
  Portless addendum of [`stack-2026-10-28.md`](stack-2026-10-28.md).
