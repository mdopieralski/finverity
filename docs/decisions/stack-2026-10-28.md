# Stack and build decisions (2026-10-28)

Context: CLAUDE.md fixes Node 22, TypeScript strict, NestJS, PostgreSQL, Kafka, and asks before any dependency
outside Nest, the Postgres driver, the Kafka client and test tooling. These are the choices made while
building v0.1.0, and why.

| Decision          | Chosen                                                                                                            | Rejected                                                       | Why                                                                                                                                                                                       |
| ----------------- | ----------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Framework version | NestJS **12** (current)                                                                                           | Nest 11                                                        | Current major. Nest 12 packages are **ESM-only**, so the project is `"type": "module"` with `nodenext` resolution and `.js` import suffixes.                                              |
| Test runner       | **Vitest 4**                                                                                                      | Jest                                                           | Nest 12's own ESM template ships Vitest; it is "the framework's default runner" for an ESM Nest app. Jest needs `--experimental-vm-modules` for ESM.                                      |
| TypeScript        | **6.0.x**                                                                                                         | 7.x                                                            | ts-tooling and typescript-eslint support < 7; Nest 12's template pins `^6`.                                                                                                               |
| Postgres access   | **`pg`** + hand-written SQL, plain `.sql` migrations, a 50-line runner with an advisory lock                      | TypeORM / Prisma / Kysely, node-pg-migrate                     | The concurrency guard is one statement; an ORM would hide it. No dependency beyond the driver.                                                                                            |
| Kafka client      | **kafkajs 2.2.4**, used directly                                                                                  | `@confluentinc/kafka-javascript`, Nest microservices transport | Mature, pure JS, explicit `autoCommit: false` + `commitOffsets`. kafkajs has had no release since 2023: a production service should evaluate Confluent's client (kafkajs-compatible API). |
| Validation        | **Hand-written** edge validators (`src/http/validation.ts`)                                                       | class-validator + class-transformer                            | Avoids two dependencies outside the allowed list; the rules (minor-unit strings, unknown fields, ids) are few and explicit. Swagger decorators document the same rules.                   |
| Logging           | Own one-line JSON writer + Nest `ConsoleLogger({ json: true })` for framework messages                            | pino / nestjs-pino                                             | No extra dependency; one line per request with an `outcome` word is all the brief asks for.                                                                                               |
| Spec source       | `@nestjs/swagger` decorators (decided by the user)                                                                | hand-written YAML                                              | Nest-native; drift is caught by `test/docs.contract.spec.ts` and `pnpm run docs:check`.                                                                                                   |
| Docs auth         | Behind the same JWT (decided by the user): Basic with the JWT as password for `/docs`, Bearer for `/openapi.json` | public docs                                                    | "All endpoints must be authenticated."                                                                                                                                                    |
| Git hooks         | **Not added** (husky/commitlint/lint-staged need the user's OK)                                                   | —                                                              | Pending. CI enforces format, lint and types instead.                                                                                                                                      |
| Timestamps        | Stored at **millisecond** precision (`date_trunc`)                                                                | microseconds                                                   | Clients (JSON, JS `Date`) express milliseconds; `asOf` and page cursors built from returned timestamps then compare exactly. Found in review.                                             |
| FX lookup         | Before the transaction opens                                                                                      | inside it                                                      | A slow rate service must not hold a connection or the idempotency-key row. Found in review.                                                                                               |

## Addendum 2026-10-30: Portless and Swagger UI serving (user, "as in ingrid")

- **Portless** (`portless@0.13.0`, dev dependency, pinned exactly) runs `pnpm start:dev` at
  `https://finverity.local` with `--lan`, as ingrid does. 0.13.1 and later require Node 24; the project is on
  Node 22. `PORTLESS=0` bypasses it. `docker compose up` is unaffected and stays the reviewer path.
- **Swagger UI** is served the ingrid way: the page, an init script with the spec embedded, and four named
  files from `swagger-ui-dist` (pinned to 5.34.0, the version `@nestjs/swagger` itself pins). It replaces
  `SwaggerModule.setup`, which exposed the whole package directory under `/docs/`. The spec is still generated
  from the decorators (`buildDocument`).
